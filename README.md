# 赤霄 · Chixiao

一只住在桌面的红金色中国龙。踩着祥云看电脑状态，闲下来会活动、伸懒腰、打盹；拖进屏幕边缘会藏起来，偶尔只探出龙头偷看你。

**独立公开版：不包含作者的账号、连接口令、聊天记录、长期记忆或电脑文件。首次启动无需账号，AI 连接默认关闭。**

## 下载即用（Windows x64）

在本仓库 **Releases** 下载 `Chixiao-Windows-x64-1.2.0.zip`，完整解压后运行 `Chixiao.exe`。不需要安装 Node.js，不需要管理员权限。请保留解压后的其他文件。

这是未签名的便携版，Windows 可能显示发布者未知。发布页同时提供 SHA-256 校验文件。Windows 10/11 x64 为当前发行目标；macOS / Linux 尚未打包验证。

## 怎么和赤霄互动

- 按住龙或祥云拖动，会显示提起与落地动作。拖进左右屏幕边缘并松手会锁定藏身；悬停祥云角会探头，移开缩回，向内拖动 96 像素后松手解锁。
- 鼠标来回轻蹭可以摸它，滚轮可以夸它；右键可陪玩、休息、开关散步或退出。
- 单击 / 双击打开对话与连接设置。
- 对话窗只有主动关闭才隐藏；失焦、重复点击、打开“用量与重置”都保留当前对话和草稿。
- 早上问好、中午提醒午饭、晚上提醒休息，使用当前电脑的本地时间。
- 云内显示本机内存、显存和温度；高负荷有对应的龙身、祥云与文字表现。

内存不需要额外工具。当前显存和 GPU 温度读取 NVIDIA 的 `nvidia-smi`；CPU 温度可读取使用者自己开启的 LibreHardwareMonitor 本机服务（端口 8085）。不支持或没有传感器时显示不可用，不虚构数值，不安装驱动。

## 可选：连接自己的 AI

在设置中选择 **本机 Ollama** 或 **本机 OpenClaw**，填入自己已运行的服务地址和模型 / 智能体名称，保存后再发送消息。程序不会下载模型、自动安装服务或从电脑上寻找口令。

- Ollama 默认示例端口 `11434`；请填写 `ollama list` 中自己已安装的模型名称。它只负责聊天。
- OpenClaw 默认示例端口 `18789`；填写你自己的网关口令和智能体名称，并在 OpenClaw 中按其说明启用 Chat Completions 接口。命令执行、记忆、工具和确认规则全部由你自己的 OpenClaw 管理。
- 仅允许 `localhost`、`127.0.0.1`、`[::1]`。没有内置作者的服务器或共享 AI 密钥。
- 默认不把电脑读数附带给 AI；可主动勾选。发送内容包含当前对话、通用角色说明和本地时间。OpenClaw 若配置了云端模型，其后续数据传输遵循使用者自己的配置。
- “停止等待”中断客户端请求，不保证撤销 OpenClaw 已开始的操作。请在 OpenClaw 自己的控制台确认任务停止。

没有包含模型权重。没有作者个人的 GitHub / Apple / Codemagic 打包监控和账号适配。

## 数据与隐私

资料独立保存在 Windows `%APPDATA%\chixiao-public`。聊天、连接设置、窗口位置和桌宠心情都从空白开始。OpenClaw 口令通过系统加密后保存，不返回给界面；系统加密不可用时拒绝保存。

不迁移其他桌宠的数据，不带遥测、广告或自动更新请求。不读取 OpenClaw 配置、浏览器资料、项目文件或长期记忆。默认只读本机硬件信息；启用 AI 后只向明确配置的本机服务发送消息；可选账号和官网读取范围见下方及 [PRIVACY.md](PRIVACY.md)。

## 可选：Claude / Codex 用量与官方重置提醒

点击“和赤霄说话”右侧的 **用量与重置**，分别选择并保存需要开启的来源。三项默认均关闭：

- **官方网站公告**：检查 OpenAI / Claude 官网、更新日志和状态公告。正常时每 15 秒检查，发现新的重置相关内容立即弹窗，只有手动关闭才收起。官网缓存、访问限制、仅在其他渠道发布的内容可能延迟或遗漏，不能保证公告发布瞬间获知。
- **Codex 账户**：需要自行安装并登录官方 Codex（Windows 优先查找官方桌面版附带的命令行程序）。通过官方 app-server 只读获取额度、可用重置和套餐，并从使用者自己的 Codex 登录文件读取官方订阅日期字段。不会把凭据交给网页或作者，不调用模型、不兑换重置。
- **Claude 账户**：在赤霄打开的独立官方窗口登录，读取官方用量与账单设置。不会复制浏览器或 Claude 桌面版的 Cookie。Claude 卡片使用橘色边框。

显示每周额度、赠送重置、订阅套餐和官方提供的到期／续费日期，不显示五小时额度。官方公告附本机转述的中文要点（预告／已执行／有条件／不会重置），以原文为准；同一时刻恢复的多个额度只提醒一次；账户卡片列出最近一次检测到的额度恢复（只写检测时间，不推算执行时间）。赠送重置到期日与订阅日期分开显示。订阅记录可能较旧，会标明官方记录更新时间；缺失字段保留未知，不推算日期。官方账户通知接口是否可用由服务提供方决定，与登录成功不是一回事。

只有赤霄运行、电脑联网且未休眠时才会监测。停用来源后停止后续读取；本机已有记录保留，退出后可删除公开版资料目录以清除全部历史和独立 Claude 登录。X 监测不在本版本中。

清空本地对话不会删除 OpenClaw 自己的记录或记忆。退出后可自行删除公开版的资料目录，回到全新状态。

## 从源码运行与打包

安装 Node.js LTS 后：

```sh
npm ci
npm test
npm run audit:release
npm start
```

Windows 打包：`npm run package:win`。脚本只将审计清单中的运行文件放入便携包，不复制用户配置、日志、测试输出、开发缓存或整个工作目录。Electron 运行时及其第三方许可随包附带。
